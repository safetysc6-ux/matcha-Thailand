# Matcha Thailand MVP

Premium Japanese-inspired matcha platform for Thai users built with:
- HTML5 + Bootstrap 5
- Bootstrap Icons
- Vanilla JavaScript
- Supabase
- AOS animation library

## Pages
- `index.html` Home landing page
- `login.html` Email login
- `signup.html` Email + Google signup
- `calculator.html` Realtime cost calculator
- `recipes.html` Recipe cards and sharing CTA
- `admin.html` Admin dashboard (MVP local CRUD UI)

## Setup
1. Replace Supabase keys in `assets/js/supabase.js`
2. Run SQL in `supabase/schema.sql`
3. Open `index.html` with a static server.
